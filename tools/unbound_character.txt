# Physics/Character — every name `tools/coverage.sh Character` reported as
# unbound, classified. Format: NAME  CATEGORY  reason.
#
# This is the list as it stood BEFORE the six REAL_GAPs below were bound; each
# of those names its new entry points and no longer appears in the tool's
# output. Re-run the tool for the current list, and read this for why the rest
# of it is not work.
#
# Two things this list exists to correct in the raw output:
#   * coverage.sh extracts bound names with `ZJOLT_API [A-Za-z_ *]*zjolt...`,
#     whose character class excludes digits — so every entry point whose
#     RETURN TYPE is a fixed-width integer (uint32_t, uint64_t, ...) is
#     invisible to it. GetUserData, GetGroundUserData and GetMaxNumHits are
#     fully bound and appear here only because of that.
#   * it matches by substring, so `CharacterID` misses zjoltCharacterGetId and
#     `ExtendedUpdate` misses zjoltCharacterUpdate.
#
# Visibility facts below are from Jolt 5.6.0 in libs/JoltPhysics:
# CharacterVirtual.h is public: at 270 and private: at 537; Character.h is
# public: at 48 and private: at 145; CharacterBase.h is public: at 55.

AddHit  INTERNAL  Override on CharacterVirtual's private nested ContactCollector/ContactCastCollector (CharacterVirtual.h:576, :598, both past private: at 537) and on a function-local collector in Character.cpp:153/:301. Called only by Jolt's own narrow-phase traversal.
CalculateCharacterGroundVelocity  INTERNAL  Private (CharacterVirtual.h:650). Integrates a contact point's arc over one step inside the update loop; what a caller wants out of it is already zjoltCharacterGetGroundVelocity.

Subclassing to swap the brute-force list for a tree is not reachable; the capability is.
