# zjolt — Physics/Constraints coverage triage.
#
# Every name `tools/coverage.sh Constraints` reports as unbound, classified.
# The list is a work list, not a score: it over-counts solver machinery that
# must never cross a C boundary and under-counts real gaps hidden behind a
# rename, so each name here carries a verdict and the reason for it.
#
# Format: NAME  CATEGORY  reason
#
#   INTERNAL         solver / island / contact-manager machinery, math and unit
#                    helpers, debug-draw internals. Nobody outside Jolt's own
#                    solver calls these.
#   EXTENSION_POINT  a C++ subclassing customisation point that zjolt already
#                    gives a caller a different way (named).
#   BOUND_ELSEWHERE  already reachable through a zjolt entry point under
#                    another name (named).
#   REAL_GAP         a caller would reasonably want it and could not reach it.
#
# One caveat about "unbound" above: coverage.sh extracts bound names with
# `ZJOLT_API [A-Za-z_ *]*zjolt...`, whose character class excludes digits, so
# any declaration whose RETURN TYPE is a fixed-width integer (uint32_t,
# uint64_t, ...) is invisible to it and its holder shows up as a false gap.
# Four names below are exactly that and are marked so.

# Totals: 112 INTERNAL, 1 EXTENSION_POINT, 49 BOUND_ELSEWHERE, 21 REAL_GAP.
#
# The one REAL_GAP left unbound: TwoBodyConstraint.
#
# Binding it means letting a C caller define a constraint type, which means
# mirroring the six-method solver vtable — SetupVelocityConstraint,
# WarmStartVelocityConstraint, SolveVelocityConstraint, SolvePositionConstraint,
# BuildIslands, BuildIslandSplits — across the boundary and calling it from
# inside the solver loop, several times per step per island. BINDING.md rules
# that out in as many words ("never as a mirrored C++ vtable"), and its
# Callbacks section names the failure mode: an unwind out of one skips the
# broad-phase shared_lock destructor and permanently deadlocks the next
# PhysicsSystem::Update. Every one of those six methods is classified INTERNAL
# above on its own merits, so binding the class would contradict the verdict on
# its own members. zjoltConstraintCreateSixDof is what a caller reaches for
# instead: per-axis free / fixed / limited, with a motor and friction on each.
#
# Four gaps outside this list were closed alongside it, because they are the
# same capability under a name coverage.sh happened to match against a
# different constraint's identically-named method:
#   HingeConstraint::GetLocalSpacePoint1 / GetLocalSpacePoint2
#     (matched zjoltPointConstraintGetLocalSpacePoint*, which is a different
#      constraint) — bound as zjoltHingeConstraintGetLocalSpacePoint1/2.
#   SliderConstraint::GetTotalLambdaPosition / GetTotalLambdaRotation,
#   PathConstraint::GetTotalLambdaPosition / GetTotalLambdaRotation,
#   HingeConstraint::GetTotalLambdaRotation
#     (all matched some other kind's GetTotalLambdaPosition/Rotation) — bound,
#      so that the breakable-joint impulse set is complete per kind rather than
#      complete for whichever kinds the literal match happened to cover.
