# Physics/SoftBody — every name `tools/coverage.sh SoftBody` reports as unbound,
# classified. One line per name: NAME  CATEGORY  reason.
#
# Two blind spots in coverage.sh's own `bound` extraction produced false gaps
# here, and both are load-bearing for reading this list:
#   1. its regex is `ZJOLT_API [A-Za-z_ *]*zjolt...`, whose character class
#      excludes digits, so any declaration returning a fixed-width integer
#      (`uint32_t zjoltShapeGetSubShapeIDBits`) is invisible;
#   2. the grep is line-based, so a declaration whose return type sits on its
#      own line (`ZJOLT_API ZJoltResult` \n `zjoltSoftBodySharedSettings...`)
#      is invisible too. That one hides a name this very file's area binds.
#
# INTERNAL          Jolt's own soft-body update calls it; nothing outside does.
# EXTENSION_POINT   a C++ subclassing hook zjolt already covers another way.
# BOUND_ELSEWHERE   reachable today through a differently-named entry point.
# REAL_GAP          a caller wants it and could not reach it — bound in this change.

CalculateRodProperties  REAL_GAP  bound as zjoltSoftBodySharedSettingsCalculateRodProperties. Mandatory for rods, not optional: it is what fills each rod's length, inverse mass and Bishop frame, and SoftBodyMotionProperties::Initialize seeds every rod's rotation from that Bishop frame, so a rod that never had it run starts at a zero quaternion.
CalculateSkinnedConstraintNormals  BOUND_ELSEWHERE  already bound as zjoltSoftBodySharedSettingsCalculateSkinnedConstraintNormals (ffi/zjolt_softbody.h:293) — a false gap, hidden from coverage.sh because that declaration's return type is on its own line.
CalculateVolumeConstraintVolumes  REAL_GAP  bound as zjoltSoftBodySharedSettingsCalculateVolumeConstraintVolumes. Nothing else runs it: CreateConstraints does not author volume constraints at all, so every tetrahedron added through the already-bound AddVolumeConstraints kept Jolt's placeholder rest volume of 1 and the solver worked to force it there.
Clone  REAL_GAP  bound as zjoltSoftBodySharedSettingsClone. There is no creation-time equivalent — the Add* calls only append, so making a variant of a finished topology meant rebuilding it from source data the host may no longer hold.
